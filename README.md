# BOT CRUPTO

Aplicação web planejada como escritório virtual 3D. O MVP-001 terá personagens que refletem atividades reais de uma simulação, com capital exclusivamente fictício e nenhuma operação financeira real.

## Funcionamento aprovado
O Analista Central de Inteligência organiza e contextualiza dados e acontecimentos simulados. Especialistas autônomos exclusivos por ativo integram esse contexto às próprias estratégias. O Coordenador de Oportunidades ordena sinais sem refazer análises ou alterar pontuações. O Gestor de Orçamento avalia pedidos de capital fictício conforme política ainda pendente. Operações simuladas geram resultados auditáveis para aprendizado individual, estratégias versionadas, validação independente e promoção/reversão automática controlada apenas na simulação.

## Estado atual
Planejamento do MVP-001, requisitos em consolidação. DOCS-001 criou a base; DOCS-002 sincronizou decisões. Inspeção atual: somente oito documentos, sem implementação e sem Git inicializado. Não existe aplicação executável. Aprovações não comprovam capacidades implementadas.

## Visual e tecnologias
Referência aprovada: um andar, análise/coordenação e orçamento no centro, mesas ao redor e expansão lateral. Visual final dos personagens/salas pendente. Three.js: PROPOSED. Frontend definitivo, backend, persistência, IA e infraestrutura não escolhidos. Dados e notícias reais somente em fase posterior, preservando contratos dos especialistas. MVP sem dependência de APIs externas pagas.
